# Roof Planner project standards

Read `BASELINE.md` and `ROOF_PLANNER_ENGINEERING_STANDARD.md` before modifying this app. The baseline defines the preserved starting point. RPES defines risk classes, calculation/data rules, verification requirements, release gates, and engineering records for subsequent work.

Preserve the established web workflow and Taylor Metal visual direction unless the user requests a change. Keep historical checkpoint tags unchanged. User-requested changes may revise the standards; document intentional changes and distinguish tested behavior from unverified requirements.
